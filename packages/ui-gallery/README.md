# Acton UI Gallery

Private visual workbench for `@acton/ui`.

The gallery is intentionally focused on visual review instead of prop
documentation. Each component page should show the practical variants, states,
and usage guidance that future Acton UI work needs to stay consistent.

Run it with:

```bash
bun dev:ui
```

or directly:

```bash
bun --filter @acton/ui-gallery dev
```
