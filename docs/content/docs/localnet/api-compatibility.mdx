a TonCenter `tvm.cell` object with base64-encoded BOC bytes. The same method is
also available through the v2 JSON-RPC entrypoints: `POST /api/v2` and
`POST /api/v2/jsonRPC`.

`/api/v2/sendBoc`, `/api/v2/sendBocReturnHash`, and the v2 JSON-RPC `sendBoc`
methods accept external-in messages only. Use `/acton_sendInternalMessage` for
local development flows that need to inject a raw internal message.

## Streaming API v2

Acton local development node supports a TonCenter Streaming API v2-compatible
subset for local tools and the bundled explorer UI. For protocol details,
request fields, finality behavior, and notification schemas, use the
[official TON Center Streaming API documentation](https://docs.ton.org/api/streaming/overview).

| Transport   | Endpoint                 | Available in local node | Purpose                                      |
|-------------|--------------------------|-------------------------|----------------------------------------------|
| `SSE`       | `/api/streaming/v2/sse`  | ✅                       | Opens a `text/event-stream` subscription.    |
| `WebSocket` | `/api/streaming/v2/ws`   | ✅                       | Opens a WebSocket subscription over JSON.    |

Localnet emits transaction, account-state, jetton-state, and trace updates.
Action extraction is not implemented yet, so action notifications should not be
used for local indexing.

## Emulate API Coverage Matrix

| Method | Endpoint                            | Available in local node | Purpose                                                                      |
|--------|-------------------------------------|-------------------------|------------------------------------------------------------------------------|
| `POST` | `/api/emulate/v1/emulateTrace`      | ✅                       | Emulates external message execution trace against current state (no commit). |
| `POST` | `/api/emulate/v1/emulateTonConnect` | ✅                       | Emulates a TON Connect transaction request against the sender wallet state.  |

`include_address_book=true` enriches the response with every address referenced by the trace.
`include_metadata=true` adds locally indexed jetton and NFT metadata, including referenced jetton
masters. `include_code_data=true` adds collected code and data cells keyed by their base64 hashes.
