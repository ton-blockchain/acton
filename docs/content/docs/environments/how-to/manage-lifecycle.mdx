<AvailabilityBadge since="Acton 1.2" />

Stop a network to release runtime resources while preserving saved state.

<Callout type="caution">
  Deleting a Studio environment removes its state and snapshots. Deleting a localnet also removes its managed Docker containers and volumes.

  Stop the environment instead if its state must be retained — deletion has no **undo.**
</Callout>

## Prerequisites

- A [virtual environment](/docs/environments/how-to/create-network).

## Stop or resume work

<Tabs items={["UI", "Simulator CLI", "Localnet CLI"]}>
<Tab value="UI">

The <kbd>Environment settings</kbd> icon at the bottom of the sidebar opens identity, endpoints, and runtime settings.

1. Open <kbd>Virtual environments</kbd> and stop the selected environment from its row actions.
1. Restart it when needed. The same environment retains its identity.
1. To rename it, open the sidebar settings, edit <kbd>Name</kbd>, and select <kbd>Save</kbd>.
1. To remove it permanently, open the settings' <kbd>Danger zone</kbd>, select <kbd>Delete environment</kbd>, and confirm.

A stopped environment still exposes settings and [snapshot controls](/docs/environments/how-to/snapshots#save-and-restore-state).

</Tab>
<Tab value="Simulator CLI">

Press <kbd>Ctrl</kbd>+<kbd>C</kbd> in the simulator terminal. Resume committed state with the same database:

```bash
acton simulator start --port 5411 --db-path .acton/simulator.sqlite
```

For state beyond committed blocks, use [simulator checkpoints](/docs/environments/how-to/snapshots#retain-simulator-checkpoints). The standalone simulator CLI has no named-network rename or delete command.

</Tab>
<Tab value="Localnet CLI">

```bash
acton localnet list
acton localnet stop dev
acton localnet start dev --detach
```

Use the same [`--state-dir`](/docs/commands/localnet#options) for commands managing a custom catalog. Resuming a named network preserves its blockchain state and does not replenish startup wallets.

To delete a network, run the interactive command and review its confirmation:

```bash
acton localnet delete dev
```

The CLI has no rename subcommand. A name belongs to its saved network definition.

</Tab>
</Tabs>

## Verify the result

- A stopped network remains listed with its saved state.
- A deleted network disappears from the catalog.
- On restart, inspect the previous block and account state before continuing work.
