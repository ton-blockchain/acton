<AvailabilityBadge since="Acton 1.2" />

Fund accounts in the selected development network. These balances are independent of testnet and mainnet.

<Callout type="caution">
  Funding changes balances on the selected simulator network or localnet. Verify the environment and recipient before submitting.

  Save a [snapshot](/docs/environments/how-to/snapshots) first if the original balances must be restored.
</Callout>

## Prerequisites

- A running [virtual environment](/docs/environments/how-to/create-network).
- A recipient address or a [configured wallet](/docs/wallets#create-a-wallet).

## Request funds

<Tabs items={["UI", "Simulator CLI", "Localnet CLI"]}>
<Tab value="UI">

1. Open <kbd>Faucet</kbd> in the selected environment.
1. Keep <kbd>GRAM</kbd> selected, enter an <kbd>Amount</kbd>, and select or paste the <kbd>Recipient</kbd>.
1. Select <kbd>Send GRAM</kbd>. Follow the resulting transaction in <kbd>Explorer</kbd>.

For simulator jettons, open the asset selector, choose a token or paste its minter address, enter an amount and recipient, then select <kbd>Mint jetton</kbd>. The jetton must be mintable and supported by the faucet. If manual simulator mining is on, select <kbd>Home</kbd> → <kbd>Mine block</kbd> to process queued funding.

Localnet provides GRAM funding — use normal contract messages for jetton minting there.

</Tab>
<Tab value="Simulator CLI">

Replace `<ADDRESS>` with the local recipient:

```bash
acton simulator airdrop '<ADDRESS>' --amount 100 --port 5411
```

With manual mining, process the queued transfer:

```bash
acton simulator mine --port 5411
```

The [jetton funding endpoint](/docs/environments/simulator/control-api) accepts HTTP requests.

</Tab>
<Tab value="Localnet CLI">

Read the Admin endpoint with `acton localnet status dev`. Replace `<ADMIN_URL>` with that URL and `<ADDRESS>` with the local recipient. The amount is in nanograms: `100000000000` is 100 GRAM.

```bash
curl --fail '<ADMIN_URL>/acton_fundAccount' \
  -H 'content-type: application/json' \
  -d '{"address":"<ADDRESS>","amount":100000000000}'
```

The localnet faucet submits a transfer from its genesis wallet and waits for API v2 to find it.

</Tab>
</Tabs>

## Verify the balance

Open the recipient in <kbd>Explorer</kbd> and inspect its balance and funding transaction. For missing transactions, use the [diagnostic checks](/docs/environments/how-to/inspect-network#verify-the-diagnosis).
