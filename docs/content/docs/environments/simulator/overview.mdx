A simulator network is Acton's simplified implementation of TON. It produces basechain and masterchain blocks without validators or consensus. Use it for local contract execution, public-network forks, and tests that need virtual time or manual mining.

Unlike with a [localnet](/docs/environments/localnet/overview), Docker is **not** required.

## Prerequisites

- [Acton](/docs/installation) 1.2 or later installed.
- An [Acton project](/docs/projects#create-or-initialize-a-project) containing `Acton.toml`.
- For startup accounts, [configured project wallets](/docs/wallets#create-a-wallet).

[Public-network forks](/docs/environments/how-to/fork-and-import#prerequisites) also require a remote procedure call (RPC) provider and any required API key. Historical forks require access to the selected block.

## Create and connect

[Create a network](/docs/environments/how-to/create-network) and [connect clients](/docs/environments/how-to/connect) through Studio or the standalone CLI. A standalone simulator serves its bundled explorer at the printed HTTP address, such as `http://127.0.0.1:5411/`.

Standalone simulators [persist committed state in SQLite and runtime state in checkpoints](/docs/environments/how-to/snapshots#retain-simulator-checkpoints).

## Simulator controls

- [Fork public state](/docs/environments/how-to/fork-and-import) and [fund accounts or mint jettons](/docs/environments/how-to/fund-accounts).
- [Control time and mining](/docs/environments/simulator/time) for time-dependent scenarios.
- [Set API conditions](/docs/environments/simulator/network-conditions) to test latency and rate-limit handling.
- [Save checkpoints](/docs/environments/how-to/snapshots) and [change blockchain configuration](/docs/environments/how-to/change-config).
- Edit account state through the [control API](/docs/environments/simulator/control-api).

## Compatibility and limits

The simulator exposes TON Center v2/v3, Streaming, Emulate, and optional LiteAPI endpoints. The [HTTP coverage matrices](/docs/environments/simulator/api-compatibility) and [LiteAPI reference](/docs/environments/simulator/liteapi) document their limits.

Message simulation in <kbd>Transaction emulator</kbd> previews execution without committing it. Sending a message to the simulator network changes its local blockchain.

The simulator does not model validator elections, consensus, or shard splitting or merging. Use a [localnet](/docs/environments/localnet/overview) for tests that depend on validator or indexer infrastructure.
