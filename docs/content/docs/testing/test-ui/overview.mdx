Test UI is a browser interface for reviewing completed `acton test` runs with traces, transaction trees, logs, source links, coverage data when tests are run with `--coverage`, and gas profiles when tests are run with `--gas-profile`.

![Test UI](../imgs/test-ui.png)

<Cards>
  <Card href="/docs/testing/test-ui/quickstart" title="Quickstart">
    Run `acton test --ui`, inspect failed tests, and navigate Info, Transactions, Logs, Coverage, and Profile tabs.
  </Card>
  <Card href="/docs/testing/test-ui/reference" title="Reference">
    Full feature reference for all Test UI sections, controls, and panels.
  </Card>
</Cards>

<Callout type="tip">
  [Acton Studio](/docs/studio) includes Test UI's results and the transaction inspector in <kbd>[Local tests](/docs/studio#local-tests)</kbd>, alongside project-wide test run history.

  For now, coverage and gas profiling are only available in the standalone Test UI, outside the Studio.
</Callout>
