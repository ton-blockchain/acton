# Counter App Template

This project was generated from Acton's `counter` template with
TypeScript app scaffold enabled. It includes a counter contract, Tolk tests and
wrappers under `contracts/`, a generated TypeScript wrapper in `wrappers-ts/`, and
a Vite-based React app in `app/`.

## Layout

- `contracts/src` contains the counter contract and shared Tolk types.
- `contracts/tests` contains integration tests.
- `contracts/wrappers/*.gen.tolk` contains Tolk wrappers generated by
  `acton wrapper` and used by tests and scripts.
- `contracts/scripts` contains deployment, increase, reset, and inspection scripts.
- `wrappers-ts/Counter.gen.ts` is the generated TypeScript wrapper consumed by the app.
- `app/` contains the React + Vite frontend.
- `package.json`, `tsconfig.json`, and `vite.config.ts` configure the app
  toolchain.
- `package-lock.json` pins the npm dependency tree for reproducible installs.

## Install

```bash
npm ci
```

## Commands

```bash
acton build
acton test
npm run test
npm run build
npm run typecheck
npm run fmt:check
npm run dev
```

## Notes

- `acton build` compiles the contract using `contracts/src/Counter.tolk`.
- `acton wrapper Counter` regenerates `contracts/wrappers/Counter.gen.tolk`.
- `acton wrapper Counter --ts` regenerates `wrappers-ts/Counter.gen.ts`.
- `npm run build` runs the contract build and the frontend build.
- `npm run test` is a placeholder dApp test script; use `acton test` for Tolk
  integration tests.
- `.github/workflows/contracts.yml` runs `acton build`, `acton fmt --check`,
  `acton check --output-format github`, and `acton test`.
- `.github/workflows/dapp.yml` runs `npm ci`, `npm run fmt:check`,
  `npm run typecheck`, `npm run build`, and `npm run test`.
- The app uses Vite, npm, shadcn-style UI primitives, and Tailwind CSS.
- Copy `.env.example` to a local `.env` for Toncenter keys. Both Acton CLI and
  the Vite app read `TONCENTER_MAINNET_API_KEY` and
  `TONCENTER_TESTNET_API_KEY`; Vite allows the `TONCENTER_` prefix via
  `envPrefix` in `vite.config.ts`.

## Manage The Counter

```bash
acton script contracts/scripts/increase.tolk
acton script contracts/scripts/reset.tolk
acton script contracts/scripts/info.tolk
```

The deployer wallet owns the counter. `COUNTER_ADDRESS` selects an existing
contract, `COUNTER_DEPLOY_VALUE_NANOS` sets the deployment value (default:
5000000), and `COUNTER_DELTA` sets the increment (default: 1).
